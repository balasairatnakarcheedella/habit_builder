# Habit Builder + Streak Tracker

A modern full-stack habit tracking app built with:

- `React + Vite`
- `Node.js + Express`
- `MongoDB + Mongoose`

## Features

- Secure signup, login, and logout
- User-specific habit storage
- Create, edit, delete, and categorize habits
- Daily and weekly habit frequencies
- Current and longest streak tracking
- Missed-day history and streak freeze support
- Motivational quotes and achievement badges
- Weekly and monthly analytics charts
- Dark mode and browser reminder settings

## Run locally

1. Copy `.env.example` to `.env`
2. Make sure MongoDB is running locally
3. Install dependencies:

```bash
npm install
```

4. Build the React frontend:

```bash
npm run build
```

5. Start the app:

```bash
npm start
```

6. Open `http://localhost:3000`

For frontend-only development, run `npm run client:dev` and keep the API server running with `npm run server:dev`.

## Environment variables

```env
PORT=3000
MONGODB_URI=mongodb://127.0.0.1:27017/habit-builder
JWT_SECRET=replace-with-a-long-random-string
NODE_ENV=development
```
